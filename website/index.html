Apple macOS Gatekeeper

Opening on macOS

macOS releases are cryptographically signed with an official Apple Developer ID Application certificate. If Gatekeeper requests confirmation on first launch, right-click SlashBeacon.app, select Open, and click Open in the dialog. Or run xattr -cr /Applications/SlashBeacon.app.

Microsoft Windows Defender

Windows SmartScreen Prompt

When launching the installer, Windows SmartScreen may show an unrecognised app alert because the binary is not signed with an enterprise EV certificate. Click More info, then choose Run anyway. You can verify the SHA-256 hash first.

Linux Permissions

Linux AppImage Execution

After downloading the AppImage, grant execution permissions: chmod +x SlashBeacon_0.5.0_amd64.AppImage. On Ubuntu 22.04+, ensure libfuse2 is installed: sudo apt install libfuse2.
